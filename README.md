# 🧠 Vision+ — Détection d’objets avec YOLOv8

Ce projet utilise le modèle **YOLOv8 (Ultralytics)** pour effectuer de la **détection d’objets en temps réel** sur des images ou des vidéos.

---

## 🚀 Objectif
Créer une application simple de **Computer Vision** capable d’identifier automatiquement plusieurs objets dans une image :
- Personnes
- Véhicules
- Objets du quotidien  

C’est une base utile pour les projets de **surveillance intelligente**, **voitures autonomes**, ou **analyse vidéo**.

---

## ⚙️ Stack technique
- **Langage :** Python 3.10  
- **Librairies :** Ultralytics YOLOv8, PyTorch, OpenCV, NumPy, Matplotlib  
- **Environnement :** Google Colab ou local  
- **Auteur :** Abel Charef
